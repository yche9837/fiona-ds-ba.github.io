2026COMP5310, pair project

Which hotel bookings will cancel? Mark 19.22/20

Hotel booking cancellation prediction for a revenue manager

Problem. More than a quarter of bookings ended in a cancellation or no-show, and late cancellations leave rooms empty that could have been resold.

What I did. Built the data pipeline that took about 120,000 raw bookings to 87,114 clean records, using chi-squared tests to decide how each column's missing values were handled and removing fields that would leak the outcome. Set up leakage-safe scikit-learn pipelines with stratified 10-fold cross-validation, tuned logistic regression and random forest models, and stress-tested the final model on later arrivals.

Outcome. A random forest that clearly beat the baselines, delivered as a decision report recommending a staff follow-up pilot, with honest limits on short-notice cancellations and the need for retraining.

Python, pandas, scikit-learn, statistical testing

Coursework repository is private. Code and report available on request.
